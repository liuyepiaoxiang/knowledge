## 0. 一页总览（TL;DR）

**你想做的事**：构建一张全人类知识与技术的基础地图，让人看清知识和技术**如何生长、又将如何演化**。

**你的三个问题，在十倍尺度下的答案**：

| 原问题 | 十倍重述 | 核心解法 |
|---|---|---|
| ① 我的知识不够全面，没法形成人类知识底图 | 任何个人的知识都不可能全面——所以**完备性不能来自"知道的人"，必须来自"生产线"** | 权威分类体系做骨架 + 海量公开语料做血肉 + LLM 做提取 + 引用网络做涌现结构 + 人工策展做质检。你的角色从"博学的人"转为"设计提取与策展管线的人" |
| ② 知识和技术之间的关系是什么 | 知识与技术是**同一生长系统在不同成熟度上的形态**，中间隔着一条可建模的"成熟度管道"，由 8 种生长机制驱动 | 一套关系本体：18 类节点 × 20 类边，每条边带方向、强度、时间、证据等级；知识长成技术走"科学→理论→方法→工艺→产品→产业"管道，技术再以仪器反哺科学，形成闭环 |
| ③ 如何有效可视化 | 不可能用一张图呈现，必须"**一个图、多种投影、多层缩放、一个时间轴**"，像地图一样用瓦片思想 | 7 种视图各回答一个明确问题（星图/地图/年轮/河流/时间轴/邻域/前沿）+ 6 级缩放金字塔 + 图瓦片切片技术 |

**本项目的差异化命题（一句话）**：
现有的一切知识类项目（维基百科、Google Knowledge Graph、OpenAlex、VOSviewer……）都在画**"知识现在长什么样"的快照**；没有人在画**"知识如何生长"的过程**——把**时间、机制、缺口**变成一等公民，就是本项目的全部新意。

**最小可行版本（8 周）**：不追求全面，先打穿 3 个样板领域（物理学、计算机、生物技术），约 150 节点 / 400 边，跑通"星图 + 时间轴 + 节点详情"三视图上线，验证两个成功标准（见 §8）。

## 1. 方法论

### 1.1 十倍法的定义

十倍法：**把每个维度的尺度放大十倍去想问题的形态，再回缩到当前可执行的最小闭环。**

对三个维度分别做两次放大：

- **高度 ×10**：这张图给谁看？从"个人学习工具"放大到"文明级认知基础设施"，再收敛到"第一批 6 类真实用户能用的网站"。
- **深度 ×10**：一个节点钻多深？从"学科目录"放大到"公式、证据链、成熟度、失败史"，再收敛到"概念卡"这一最小深度单元。
- **广度 ×10**：覆盖多宽？从"STEM 学科"放大到"全部人类知识 + 全部文明传统 + 显性与隐性知识"，再收敛到"12 宏观域的骨架 + 3 个样板域打穿"。

三个维度不是并列的，它们合起来回答同一个问题的三个侧面：

```
底图 = 数据模型(广度) × 关系本体(深度) × 渲染投影(高度)
        ↑从哪里来        ↑长什么样         ↑怎么看
```

### 1.2 一个前提判断：为什么是现在

这张图在历史上被多次梦到，但**只有现在才可能做成**：

- 1900s：Otlet 的 Mundaneum（世界知识馆）——人工卡片时代，失败于人工无法扩展。
- 1937：Wells 的《World Brain》——只留下概念。
- 1945：Bush 的 Memex——机器太弱。
- 2001–：Wikipedia / Wikidata——把"存量知识"结构化了，但没有"生长"维度。
- 2010s：Microsoft Academic Graph / OpenAlex——25 万级论文图，但对象是**文献**不是**概念**。
- **2020s：LLM + 开放语料 + WebGL 三者同时成熟**——第一次，"从非结构化人类文本中自动抽取概念级知识关系"在工程上可行了。

结论：你不需要"知道一切"，你需要**站在这个时代唯一存在的那条生产线上**。

## 2. 高度扩展

### 2.1 十倍阶梯：这张图给谁看

从一张个人学习图出发，每十倍抬升一次视野：

| 层级 | 尺度 | 形态 | 典型用户 |
|---|---|---|---|
| L1 | 个人 | 学习路径图 | 你自己 |
| L10 | 团队 | 研发知识地图 | 创业团队、研究组 |
| L100 | 行业 | 技术全景图 | 产品经理、投资人、猎头 |
| L1000 | 国家 | 科研战略仪表盘 | 政策制定者、智库 |
| L10000 | 文明 | 认知基础设施 | 所有人 + AI Agent |

**关键洞察：最高层的主要用户不是人，是 AI。** 到 L10000 这一层，这张图的最大消费者是未来的 AI Agent——它们需要一张"概念级的世界结构底图"来做推理与落地（grounding）。这决定了架构上必须 **API-first**：网页只是这张图的一个视图，接口才是本体。

### 2.2 愿景的三句话

1. **图不是领域（territory），图是模型。** 所以诚实性优先于完整性：每个节点带置信度，每条边带证据，被推翻的知识不删除而是标记为"化石分支"（见 §3.4），我们不知道的领域标记为"未知之地"（terra incognita）。
2. **这张图的第一公民是"变化"。** 时间轴不是附属功能，而是坐标系本身：任何视角都应该能拖动时间滑块，看到 1650 年、1900 年、2026 年的同一片区域。
3. **看懂生长比记住结构更重要。** 图上要能回答：这里为什么繁荣？那里为什么停滞？这两团东西为什么至今没有连线？——答案在 §5 的 8 条生长机制里。

### 2.3 先例谱系与本项目的位置

| 先例 | 画了什么 | 缺了什么 |
|---|---|---|
| Mundaneum（1900s） | 人工知识分类宇宙 | 无法扩展、无时间维度 |
| Wikipedia / Wikidata | 存量知识的众包结构 | 条目间关系弱、无生长模型 |
| OpenAlex / MAG | 2.5 亿级论文引用图 | 节点是文献不是概念，人类无法阅读 |
| Atlas of Economic Complexity | 产品空间网络 + 用结构预测出口增长 | 限经济领域（但它证明了"结构→预测"这条路走得通） |
| Paperscape / VOSviewer / Connected Papers | 论文星图、文献邻域 | 都是快照，机制与缺口不可见 |

**Delta 命题**：以概念与技术为节点（而非文献）、以生长机制为模型（而非引用计数）、以缺口与预测为输出（而非检索）。

## 3. 深度扩展

### 3.1 节点的深度阶梯

从目录到证据，共七层：

```
L1 学科(物理学) → L2 子领域(凝聚态物理) → L3 主题(超导) → L4 概念(库珀对)
→ L5 命题(BCS方程) → L6 证据链(1972诺奖论文+实验复现记录) → L7 原始文献
```

十倍原则：**网站用户默认停在 L4，愿意的人随时能下钻到 L7；但管线必须全七层打通**，否则 L4 之上的"深度感"是假的。

### 3.2 最小深度单元：概念卡

每个概念节点的标配（这就是"深度"的最小可交付物）：

```yaml
概念卡:
  一句话定义: "两个电子通过晶格振动耦合形成的束缚态"
  为什么重要: "超导电性的微观基础"
  一个具体例子: "铅在 7.2K 以下电阻消失"
  前置概念: [晶格振动(声子), 费米面, 泡利不相容]
  通向哪里: [高温超导, 约瑟夫森结, 超导量子比特]
  未解决的问题: [高温超导机制至今无共识]
  证据: [{来源: Nobel 1972, 等级: A}]
```

### 3.3 时间深度

不只是"近两百年科学史"：

- **远古层**（压缩展示）：火、轮子、农业、文字、冶金——它们是文明知识树的"大爆炸原点"，作为少数高亮锚点放在时间轴最左端。
- **主干层**（1500–1900）：科学革命、工业革命。
- **加速层**（1900–）：现代学科分化与交叉。
- **实时层**（滚动更新）：arXiv/patent/GitHub 的活水。

### 3.4 三层分离：地图 ≠ 图书馆（关键架构决策）

这是深度扩展里最重要的一个设计决策——**很多知识图谱项目死在这里**：

| 层 | 对象 | 数量级 | 角色 |
|---|---|---|---|
| **地图层** | 概念、理论、技术、工艺、材料、工具、问题 | 10⁵–10⁶ | 人看的那张"图"，节点是**被理解物** |
| **证据层** | 论文、专利、标准、书 | 10⁸ | 不直接上图，只作为边的**引用证据**挂载 |
| **事件层** | 人物、组织、发现/发明事件、争议 | 10⁶–10⁷ | 提供时间与叙事，挂在边上（"谁、何时、验证了"） |

图书馆项目把 10⁸ 个文献节点画出来，人根本看不了。本项目的图只画 10⁵ 量级的"被理解物"，文献降级为证据——**这一刀切下去，可视化问题就解决了 80%**。

### 3.5 深度的第四维：状态与成熟度

每个节点除了"是什么"，还必须携带"现在怎么样"：

| 知识侧状态 | 技术侧状态（TRL 对齐） |
|---|---|
| 共识（教科书级） | TRL 9 已量产 |
| 主流但开放（有活跃修正） | TRL 6-8 工程验证 |
| 争议中（多阵营） | TRL 3-5 实验室 |
| 前沿假说 | TRL 1-2 原理设想 |
| 化石（被推翻，保留教学价值） | 失败/停产（保留教训） |

### 3.6 化石层与未知层（诚实性的一等公民）

- **化石分支**：燃素说、以太、冷聚变、Lamarckism……不删除，灰化显示，挂"它为什么死了"的证据边。**科学如何自我纠错，本身就是这张图最想让人看见的"生长"**。
- **未知之地**：未解决的重大问题（黎曼猜想、常温常压超导、意识的神经基础、可控核聚变的等离子体约束）在图上以"龙出没"（here be dragons）标记——它们不是空缺，而是**最亮的缺口**。

## 4. 广度扩展

### 4.1 十二宏观域

广度 ×10 意味着不止 STEM。12 宏观域作为缩放金字塔的第一层：

| # | 宏观域 | 覆盖 | 与其他域的典型交叉 |
|---|---|---|---|
| 1 | 形式科学 | 逻辑、数学、统计、理论计算机 | 一切（它是全图的"骨架材料"） |
| 2 | 自然科学 | 物理、化学、天文、地球、生物 | 工程、医学 |
| 3 | 工程与技术 | 各工程学科、材料、能源、信息、制造 | 科学、产业 |
| 4 | 医学与健康 | 临床、药学、公共卫生、神经 | 生物、化学、伦理 |
| 5 | 农业与食品 | 种植、养殖、食品工程、土壤 | 化学、生态、经济 |
| 6 | 社会科学 | 经济、社会、心理、政治、传播 | 统计、历史、政策 |
| 7 | 人文学科 | 历史、哲学、语言、文学、考古 | 一切（意义的解释者） |
| 8 | 艺术与设计 | 美术、音乐、建筑、影视、游戏 | 技术（工具史）、心理（感知） |
| 9 | 法律与治理 | 法学、制度、国际关系 | 经济、历史、技术伦理 |
| 10 | 经济与商业 | 产业、金融、管理、创业 | 工程（产业化）、法律 |
| 11 | 教育与传播 | 教学法、认知科学、媒体 | 一切（知识自身的繁殖机制） |
| 12 | 实践技艺与生活 | 烹饪、手工艺、体育、园艺、修理 | 材料、生理、文化 |

注意第 12 域和第 11 域：**隐性知识（老师傅的手感、教学的诀窍）也是人类知识的主体部分**，十倍广度必须包含它——哪怕初期只能以"技能节点 + 文献/影像证据"的浅层形态存在。

### 4.2 文明广度

知识史不是"希腊→欧洲→全球"单线。骨架上必须显式保留：中国技术传统（四大发明之外的冶铁、水利、医药）、印度数学与语法传统、阿拉伯黄金时代（代数、光学、医学）、非洲与美洲原住民的农业与天文、口传传统。实现方式：节点带 `tradition`（知识传统）字段，时间轴默认并置多文明，而不是以欧洲纪年为主线。

### 4.3 横切层（跨域维度）

12 个宏观域之上还有 5 个贯穿一切的正交层：

```
方法层(统计/优化/建模)  工具层(仪器/软件)  数据层(数据集/标准)
人物层(科学家/工匠)     事件层(发现/发明/失效)
```

横切层是"知识交叉"实际发生的地方——迁移律（§5.7）的载体。

## 5. 理论内核：知识到底如何生长（8 条机制）

这一节是整个项目的**物理学**。你问"看清知识和技术如何生长"——图不是把东西连起来就完了，**必须把这 8 条机制编码进图的结构里**，用户才能在图上"看见生长"。

| # | 机制 | 驱动力 | 在地图上的视觉表现 | 经典案例 |
|---|---|---|---|---|
| 1 | **组合律** | 新知识 = 旧知识的重组（Schumpeter；专利引证网络已实证） | 高连通度节点的密集区持续冒出新节点 | 智能手机 = 电话+相机+电脑+GPS |
| 2 | **邻近可能** | 只能长在已有结构的边缘（Kauffman） | 新节点高度聚集于成熟簇的边界，跳跃性空白罕见 | 没有半导体就"不可能"出现软件业 |
| 3 | **工具循环** | 技术造仪器→仪器开新观察→新观察生新理论→新理论生新技术（闭环！） | 一条显式的环形回流边（技术→仪器→科学） | 显微镜→细胞学说；冷冻电镜→结构生物学爆发；LLM→AI for Science |
| 4 | **范式转移** | 危机积累→非线性重构（Kuhn） | 局部图谱的"地质断层"：时间滑块拖过某年，一大片边被重连 | 牛顿力学→相对论；经典遗传学→分子遗传学 |
| 5 | **楔形分叉** | 争议节点分裂出新分支 | 一个节点裂成两个、中间一条红色争议边 | 光的本性之争→波粒二象性；符号主义 vs 连接主义→神经符号融合 |
| 6 | **迁移律** | 方法跨域搬迁产生新领域 | 一条长距离跨簇边，端点两侧各有一个新节点发芽 | 统计→机器学习→蛋白质折叠；博弈论→拍卖机制设计 |
| 7 | **瓶颈决定论** | 生长卡在测量/材料/算力/理论四类瓶颈上 | "高介数中心性 × 低成熟度"的节点自动标记为瓶颈 | 没有玻璃透镜就没有微生物学；算力卡住 AGI |
| 8 | **化石律** | 被推翻/被替代的知识不消失，成为沉积层 | 灰色化石分支 + "被谁取代"边 | 燃素说→氧化说；地心说→日心说 |

**设计含义**：这 8 条机制分别对应图上 8 类可被查询/渲染的**结构模式**。也就是说，"看见生长"不需要用户懂理论，只需要网站把这些模式做成可视的图层（详见 §9.2 的前沿视图）。

### 5.1 成熟度管道：知识如何长成技术

问题②的正面回答。知识与技术不是两类东西，是同一根管道里的不同成熟度：

```
科学发现 → 理论成熟 → 方法成型 → 工艺突破 → 产品出现 → 产业形成
    ↑                                                        │
    └──────────── 仪器反哺（工具循环）←──────────────────────────┘
```

管道的实证特征（写进数据模型）：

- **时滞可测**：从科学发现到产业化的时滞，各领域差异巨大（激光：40 年；mRNA：15 年；深度学习：30 年）。**时滞本身是节点的属性**，也是预测的原材料。
- **漏斗很陡**：10⁴ 个科学发现 ≈ 10³ 个方法 ≈ 10² 个工艺 ≈ 10¹ 个产品。图的密度从左到右骤减——这个"漏斗形状"本身要可视化。
- **反哺是常态不是例外**：产业赚的钱和产的仪器回流科研。闭环必须显式建边，否则"生长"就断了。

## 6. 关系本体设计（解问题②）

### 6.1 节点类型（18 类）

| 类型 | 定义 | 示例 |
|---|---|---|

### 6.3 一个完整示例：晶体管的奠基链

```
[命题]麦克斯韦方程组 ─奠基→ [理论]量子力学 ─奠基→ [理论]能带理论
   │                                                        ↓
   │(工程化)                                         [概念]带隙/载流子
   ↓                                                        ↓
```

用户点开任何一个节点，都能沿边走完整条链——这就是问题②的最终答案：**关系不是一种，是一族；不是静态的，是带时间戳的；不是等权的，是带证据分级的。**

## 7. 数据完备性方案（解问题①）

### 7.1 核心转念：从"我知道"到"我能提取"

你缺的不是知识，是**生产线**。完备性来源五路，缺一不可：

```
① 权威分类体系 → 骨架（保证不缺大块）
② 公开语料     → 血肉（保证细节可提取）
③ LLM 提取管线 → 劳动力（保证规模化）
④ 引用/共现网络 → 涌现结构（保证客观性：结构是"算"出来的，不是"编"出来的）
⑤ 人工策展     → 质检（保证可信）
```

### 7.2 五路来源明细

| 来源 | 给什么 | 规模 | 用法 |
|---|---|---|---|
| 分类法：MSC2020、PACS、IPC/CPC 专利分类、MeSH、中图法、UNESCO、JEL | L1–L3 骨架 | ~10⁴ 类目 | 直接映射为节点，**这是"不缺大块"的保险** |
| Wikipedia 300+ 语言 + Wikidata | 概念定义与关系种子 | 6×10⁷ 条目 | LLM 抽取首句定义与 infobox 关系 |
| OpenAlex / Semantic Scholar | 引用网络→涌现聚类 | 2.5×10⁸ 文献 | 算社区发现→自动建议"主题"边界 |
| 专利库（USPTO/EPO/CNIPA） | 技术侧节点与产业边 | 10⁸ | CPC 分类+引证网络映射技术树 |
| 书籍目录、开源库、标准库、菜谱/手工艺文档（第 12 域） | 广度补全 | 10⁷ | 按域优先级分期接入 |

### 7.3 管线五步

```
抓取 → LLM 提取(节点/边/置信度) → 对齐合并(消歧:同一概念多语言多写法)
    → 置信度分级(A/B/C/D) → 策展队列(人工抽查+冲突仲裁) → 发布(带版本号)
```

**证据分级**（诚实性的机制化）：

| 等级 | 含义 | 来源 |
|---|---|---|
| A | 权威文献直接支持 | 论文/教科书/专利原文 |
| B | 专家共识/权威分类法 | 分类体系、百科高引用条目 |
| C | LLM 自动抽取，未人工复核 | 管线产物 |
| D | 推测/用户贡献，仅作探索线索 | 社区 |

默认只展示 B 以上；C/D 层可开关（"显示推测层"）。

### 7.4 完备度的度量（让"不够全面"变成可管理的数字）

- **骨架覆盖率**：对 MSC/IPC 等参照分类法的映射率（目标 MVP 期 >90%）
- **孤岛率**：边数=0 的节点占比（<15%）
- **悬边率**：指向不存在节点的边占比（<1%）
- **证据覆盖率**：带 A/B 证据的边占比（分域报告）

**完备性从此不再是一个"我感觉不够"的心理问题，而是一组持续改进的指标。**

## 8. 演化与预测层：未来如何呈现

你要求"看清未来会如何演化"。诚实的设计立场：**不做预言，做三种概率化产品。**

### 8.1 演化信号层（已发生的"未来"）

持续接入并可视化的先行指标：论文共被引突增、专利分类对共现、基金流向、人才迁移、开源依赖图变化、标准立项。它们渲染为地图上的**生长热力层**——哪里在变亮，一目了然。

### 8.2 邻近可能引擎（缺口的算法化）

规则：若 A、B 两个簇各自成熟（节点密度高、活跃度上升），但 A→B 的边不存在或极稀疏——输出"**待连接对**"。这是 Atlas of Economic Complexity 用产品空间预测出口增长的同款逻辑，搬到知识空间。渲染为地图上的**虚线边**，标注"此处可能尚未发生的连接"。例：因果推断 × 蛋白质设计？公共卫生 × 游戏引擎？

### 8.3 情景推演 + 预测登记簿（可证伪的未来）

- **情景推演**：对每个瓶颈节点（§5 机制 7）生成"若突破/若卡住"两支情景，不预测哪支必然发生。
- **预测登记簿**：所有推演写成带日期、带置信度的可证伪陈述（"若 X 信号出现则 Y 概率上升"），存入登记簿，**定期回测校准**（Tetlock 式纪律）。这是"未来层"与民科预言的分界线。

## 9. 可视化设计（解问题③）

### 9.1 总原则：一图多投影

一张万能图不存在。原则是：**同一张底图数据，渲染成 7 种视图，每种只回答一个明确的问题。** 用户问什么问题，看什么视图。

### 9.2 七视图

| 视图 | 回答的问题 | 视觉隐喻 | 主要交互 |
|---|---|---|---|
| **星图** | 全景长什么样？哪里大哪里小？ | 银河系：簇=星系，节点=星，边=引力丝 | 缩放平移、悬停高亮邻域 |
| **地图** | 领域之间怎么"接壤"？从 A 走到 B 最近的路径？ | 大陆/城市/道路（主隐喻） | 路径规划式查询："从量子力学到 mRNA 疫苗" |
| **年轮** | 这个领域多老？什么时候出生的？ | 树干年轮：一圈=一个年代 | 时间滑块拖动，看 1650/1900/2026 |
| **河流** | 知识怎么变成技术再变成产业？ | Sankey 河：科学→…→产业的成熟度管道（§5.1） | 点任一河段看上下游 |
| **时间轴** | 按时间发生了什么？ | 横向事件流+多文明并置 | 过滤域/文明/类型 |
| **邻域** | 我关心这一个概念的来龙去脉？ | 自我网络（ego graph）+ 概念卡 | 双击下钻到证据层 |
| **前沿** | 现在哪里在快速生长？哪里卡住了？哪里可能漏接？ | 热力层(活跃)/红色层(瓶颈)/虚线层(待连接) | 图层开关 |

### 9.3 缩放金字塔 + 图瓦片（性能问题的根治方案）

百万级节点直接渲染必死。解法 borrowed 自在线地图：**把图按空间预切成瓦片（graph tiles），按需加载**。

| 层级 | 显示 | 数量级 | 交互 |
|---|---|---|---|
| z0 国家 | 12 宏观域 | 12 节点 | 点进 |
| z1 大陆 | ~150 子领域 | 10² | 点进 |
| z2 城市 | ~2k 领域 | 10³ | 悬停概要 |
| z3 街区 | ~2 万主题 | 10⁴ | 悬停定义 |
| z4 建筑 | ~10 万概念 | 10⁵ | 概念卡 |
| z5 室内 | 单节点详情 | 1 | 证据链/概念卡/邻域 |

每个视口只加载可见瓦片，10 万节点在 WebGL 下实时流畅，百万级也不怕。

### 9.4 技术选型（建议，非强制）

- **渲染**：WebGL——`Cosmos.gl`（为百万节点图而生）或 `Sigma.js`（成熟、文档全）或 `deck.gl`（如需地理叠加）。
- **前端框架**：Astro（静态为主、岛屿交互，最省）或 Next.js（要 API 路由时）。
- **数据**：构建期把图预计算成瓦片 JSON（Python 脚本 + 社区发现算法）；运行期查询走轻后端或静态文件。MVP 阶段**不需要**图数据库，一个版本化的 JSON 就够；上量后再考虑 Kùzu/Neo4j。
- **LLM 管线**：Python + 便宜模型批量抽取 + 贵模型复核冲突。

### 9.5 交互细节规范

- 悬停：局部高亮 + 最小信息（名称+一句话）；单击：概念卡侧栏；双击：下钻一级。
- 时间滑块全局常驻（愿景第 2 条的落实）。
- **"给我讲个故事"模式**：预置 20 条叙事路径（如"一粒沙如何变成你手里的手机"），导览式播放——冷启动用户的最佳入口。

## 11. 路线图：MVP 与三期计划

### 11.1 反模式先行声明

最大的死法是"等知识全面了再上线"——永远不会全面，所以永远不上线。**对策：版本化发布 + 不均匀推进（打穿样板域而非摊平所有域）。**

### 11.2 MVP（8 周）：三个样板域打穿

选物理学、计算机、生物技术——三者恰好完整覆盖"科学→技术→产业"管道，且有最丰富的开源语料。

| 周 | 交付 |
|---|---|
| W1–2 | 本体 Schema v0.1 定稿；人工+LLM 协作播种 3 域 ×~150 节点 ×~400 边 |
| W3–4 | 星图视图 + 时间滑块 + 节点详情页（概念卡），静态 JSON 驱动，本地可演示 |
| W5–6 | LLM 提取管线 v0：从 Wikipedia/Wikidata 自动抽边并打置信度；证据分级上线 |
| W7–8 | 部署公网 + `/about` 方法论页 + 收集首批反馈 + 定稿完备度指标 |

**MVP 成功标准（两个，都能当场验证）**：

1. 一个高中生能沿"沙子→硅→晶体管→手机"走通一条完整奠基链。
2. 一个投资人能看懂"mRNA 疫苗"从实验室到产业的路径与关键瓶颈节点。

### 11.3 三期全景

- **Phase 1（3–6 月）**：管线自动化 → 1 万节点；策展队列 UI；邻域/地图视图；完备度指标公开。
- **Phase 2（6–18 月）**：时间维全量 + 河流/前沿视图；邻近可能引擎 v0；预测登记簿；12 宏观域骨架全覆盖。
- **Phase 3（18 月+）**：社区策展（贡献/仲裁机制）；多语种；开放 API 稳定；AI Agent 消费端。

## 13. 风险与反模式

| 风险 | 表现 | 对策 |
